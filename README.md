# 📖 Sobre o Projeto

O **Projeto Car** é uma landing page desenvolvida para apresentar veículos de forma moderna e atrativa.

O projeto foi criado com foco em design responsivo, organização visual e boas práticas de desenvolvimento Front-end, utilizando apenas tecnologias nativas da web.

Durante o desenvolvimento foram aplicados conceitos de estruturação semântica, estilização avançada e interatividade com JavaScript.

---

# ✨ Funcionalidades

- 🚗 Interface moderna para apresentação de veículos;
- 🎨 Design inspirado no mercado automotivo;
- 📱 Layout responsivo;
- ⚡ Navegação intuitiva;
- 💻 Estrutura organizada e de fácil manutenção;
- 🖱️ Interações desenvolvidas com JavaScript.

# ⚙️ Como executar

Clone este repositório:

```bash
git clone https://github.com/Henrique-Wandersee/Projeto_CAR.git
```

Entre na pasta do projeto:

```bash
cd Projeto_CAR
```

Abra o arquivo **index.html** diretamente no navegador.

Para uma melhor experiência durante o desenvolvimento, utilize a extensão **Live Server** do Visual Studio Code.
